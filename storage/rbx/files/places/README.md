# starting places

a new place starts as a copy of the baseplate for the client year you pick.

- `2016.rbxl` is the 2016 roblox studio baseplate, from the karma 2016 client
- `2012.rbxl` is crossroads, the classic starter place, from kitaske's uncopylocked game collection. if it's missing, 2012 places use `2016.rbxl`
