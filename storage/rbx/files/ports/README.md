# ports

places converted to run on the 2016 client with tools/place2016.

- VV_MMV_2016.zip: the vv mmv summer update place. unzip it to get VV_MMV_2016.rbxlx (about 204 MB). it is too big for the place upload form, so put it in place by hand (see tools/place2016/README.md) and set the game to the 2016 client.
- RateMyAvatar_2016.zip: the rate my avatar booth game (bewerte meinen avatar 2). unzip it to get RateMyAvatar_2016.rbxlx (about 21 MB). it fits the place upload form. set the game to the 2016 client. the scripts are in tools/place2016/ports/rma.
